# 《庄子》逐篇白话与注释：任务说明

仓库根目录（下称 ROOT），即 `~/Documents/庄子`。命令里用相对路径，在 ROOT 下运行。

## 输入
- 原文：`ROOT/data/src/NN-id.txt`，每行一段，来自维基文库，已转简体。**这是唯一依据，一个字、一个标点都不能改、不能增删、不能调序。** 原文里个别字看着像错字（如“无”“邪”“县”“女”），那是古本写法或通假字，照抄，用注释说明。
- 样板：`ROOT/data/03-yangshengzhu.json`（《养生主》）。动手前先完整读一遍，格式、注释密度、翻译口吻都照它来。

## 输出
每篇一个文件 `ROOT/data/NN-id.json`（NN、id 与原文文件名相同），结构：
```json
{"n": 1, "id": "xiaoyaoyou", "title": "逍遥游", "part": "内篇",
 "intro": "两三句大白话：这一篇讲什么、最有名的故事是哪个",
 "sections": [ {"title": "小标题", "sents": [ {"o": "原文（带标记）", "t": "白话"} ]} ]}
```
- **sections 与原文段落一一对应**：原文第 k 行 = 第 k 个 section，数量必须相等。
- section 的 `title`：4–10 个字，点出这一段讲的故事或道理，像目录条目（如“鲲鹏展翅”“庄周梦蝶”“朝三暮四”“惠子的大葫芦”）。
- `sents`：把一段原文按句切开，一般在 。！？ 或引号收尾处切；太长的句子可在逗号处切。**把一段里所有 o 去掉标记后首尾相接，必须与原文这一行完全一致。**
- `t`：这一句的白话翻译。

## 注释标记（写在 o 里）
- `{字|拼音}` 只注音；`{词||解释}` 只释义；`{字|拼音|解释}` 两者都要。
- 拼音带声调，音节之间空格，音节数 = 字数（如 `{踌躇满志|chóu chú mǎn zhì|…}`）。
- 标记不能嵌套，不能跨越标点以外的结构；被标记的文字必须原样出现在原文里。

**注音（拼音）只给“读音会卡住”的字：**
1. 生僻字（常用 3500 字以外的），包括所有扩展区生僻字
2. 多音字在这里取了不常见的读音（如 中 zhòng、间 jiàn、更 gēng、恶 wū、说 yuè、女 rǔ）
3. 读音变了的通假字，按通假后的读音标（如 县 xuán 通“悬”、知 zhì 通“智”）；读音没变的通假字（如 反 通“返”）只释义、不注音
4. 难读的人名、地名
同一篇里同一个字同一读音，前两三次出现标注即可，后面可以不再标。读音容易认的常用字不标。

**释义只给“意思会卡住”的词：**
古今异义、通假字（写“同‘某’”或“通‘某’”）、专有名词（人物/典籍/地名，一句话交代）、庄子的关键概念（如 逍遥、齐物、无待、坐忘、心斋、天籁）、特殊的虚词用法。解释简短，一般 4–20 字；有两种通行说法时写“一说……”。
密度参考样板：大约每 7–12 个字一处标记。宁可少而准，不要每个词都标。

## 翻译要求
- 自己写，**不要照搬任何现代译本**（陈鼓应、方勇、王世舜等都有版权）。依据是公版古注（郭象注、成玄英疏、王先谦《庄子集解》等）和通行理解。
- 忠实原意，口语、好读，像讲给一个聪明的朋友听；对话保留引号。必要时可以用括号补一两个字让意思连贯。
- 不确定、有争议的地方，按最通行的理解翻，并在相关词的释义里写“一说……”。

## 校验（必须做到全部通过）
写完每篇就跑：
```
"ROOT/.venv/bin/python" "ROOT/tools/validate.py" NN
```
- 出现“错误”必须修到没有。最常见的是原文不一致：对照报错位置逐字修 o。
- “读音提醒”是程序拿词库比对的结果，逐条看：通假字、古音的读法如果你确认是对的就保留；是你标错了就改。

## 收尾
全部篇目校验通过后，回复一份简短报告：每篇的段数、注释数、保留了哪些“读音提醒”（各一句理由）、翻译时拿不准的地方（如有）。不要改动 data/src、tools、其他批次的文件。
